# M&Q brand assets

Source: `McAllister & Quinn Homepage.html` (a saved copy of the firm homepage,
uploaded for branding reference).

Extracted and used by the demo (`ui/live.html`) and vendored under `ui/vendor/`:

- **Palette**: navy `#003c71`, gold `#c79844`, cyan `#26abe0`, cyan-soft `#85cfde`.
- **Typeface**: Hanken Grotesk (Google Fonts, OFL-1.1) - vendored as a variable
  woff2 at `ui/vendor/fonts/hanken.woff2`.
- **Logo**: the diamond/gem emblem, `mq-diamond-source.svg` (also inlined into the
  demo header and favicon).

The homepage HTML has no extractable raster assets (no data-URIs, no `_files/`).
